Comments got both halves of emoji: a picker for writing them, and one-tap reactions for when a reply would be too much.

- **A picker in the composer** — 238 emoji across eight categories, with search
- **It inserts where your cursor is**, not at the end, so you can drop one mid-sentence
- **React to any comment** with a tap — the count tells you how many people picked each one, and the ones you picked are marked
- **Tap again to take it back.** Use as many different emoji as you like on the same comment; the same one only ever counts once

Search matches names *and* keywords, and puts the obvious one first — type `star` and you get ⭐, not 💫. `lol` finds 😂, `+1` finds 👍, `ship` finds 🚀.

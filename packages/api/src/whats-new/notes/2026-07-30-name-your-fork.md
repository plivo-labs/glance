Forking used to happen the instant you clicked it — you got a copy called `something-copy` and found out what it was called afterwards. Now **Fork** opens a dialog first.

- **Name it yourself** — prefilled with the original's name plus *(copy)*, so hitting Fork straight away still does the obvious thing
- **See the address before you commit** — the URL is derived from the name as you type and shown under the field
- **Choose who can see it** — the picker defaults to the original's visibility, so a fork of a private page stays private unless *you* widen it
- **One dialog, both routes** — the menu in the viewer and the row menu on your dashboard now open the same thing

Pick a name whose address is already taken and the dialog stays open with the reason, so you can edit it rather than start again.

A script can now do the things you do in Glance — deploy a build, publish a report, push a dashboard — without borrowing your login. **Settings → API Keys** mints one.

- **Copy the secret once.** It's shown at mint time and never again; Glance only keeps a hash of it
- **Export it as `GLANCE_TOKEN`** and the CLI runs without `glance login`. The same key is a bearer token against the HTTP API, so `curl` works too
- **Grant only what it needs** — all your sites or a chosen few, read or write. A key's access can never be wider than your own
- **It can create and deploy, never delete** — and it can't mint or revoke keys, whatever you grant it
- **Revoke instantly** from the same screen. Revoked keys stay in the list, marked, so you can see what was retired and when

You choose how long a key lives when you mint it, and you can hold ten active at a time. **How keys work** on the keys screen has the full rules.
